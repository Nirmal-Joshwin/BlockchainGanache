# Blockchain Flow Mechanism

This document outlines the exact mechanism of a vote transaction in the Secure Blockchain Voting System.

1. **User connects MetaMask**: The user opens the React DApp. MetaMask injects the `window.ethereum` object.
2. **MetaMask identifies the Ethereum account**: The DApp requests access, and the user approves, exposing their **address** (e.g., `0x123...`).
3. **React requests a voting transaction**: The user clicks "Cast Vote". React triggers the `vote()` method on the `SecureVoting` smart contract instance via Web3.js.
4. **MetaMask asks the user to sign the transaction**: A popup appears detailing the **gas** cost and the target **contract address**. The user clicks "Confirm".
5. **The transaction is sent to Ganache**: The signed **transaction** payload is broadcast to the local Ganache RPC endpoint (`http://127.0.0.1:7545`).
6. **The SecureVoting smart contract executes**: The EVM on Ganache executes the `vote()` function logic.
7. **Contract validation rules are checked**: The contract checks `require(electionState == Active)`, `require(!voters[msg.sender])`, and validates the candidate ID.
8. **Vote state is updated**: The contract state variables (the `voters` mapping and the `candidates` mapping) are updated in memory.
9. **An event is emitted**: The contract emits a `VoteCast` **event**, containing the voter's address and candidate ID.
10. **Ganache mines/confirms the transaction**: Ganache bundles the transaction into a new **block**. The transaction becomes CONFIRMED, generating a unique **transaction hash**.
11. **The frontend reads the updated contract state**: React listens to the `VoteCast` event, automatically updating the UI with the new vote counts and the transaction hash.

## Terminology
- **Account**: An Ethereum identity capable of signing transactions.
- **Address**: A 42-character hexadecimal string representing an account.
- **Transaction**: A cryptographically signed instruction that alters blockchain state.
- **Smart Contract**: Immutable code deployed on the blockchain that dictates logic.
- **Block**: A batch of transactions permanently recorded on the blockchain ledger.
- **Gas**: A measure of computational effort required to execute the transaction.
- **Transaction Hash**: A unique identifier for the executed transaction.
- **Contract State**: The persistent memory/storage variables within the smart contract.
- **Event**: A log generated by the contract that external applications can listen to.
